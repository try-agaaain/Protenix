## 1. 模型输入的核心挑战

本文承接 [数据预处理完全指南](preprocessing_guide.md)，介绍预处理输出的特征字典如何流入神经网络。蛋白质结构预测面对的输入是**多模态、多尺度、多来源**的：

- **多模态**：有氨基酸序列（符号）、有原子坐标（连续数值）、有 MSA（矩阵）、有模板（三维结构）
- **多尺度**：原子级（每条链几十到几百个原子）、token 级（每条链几十到几百个残基）、链级、复合物级
- **多来源**：实验坐标来自 PDB、序列来自 UniRef、模板来自历史结构、物理属性来自化学常数

神经网络无法直接处理这些异构输入，必须先将它们统一投影到**同一维度的实值向量空间**中，才能用注意力机制和前馈网络进行推理。

Protenix 的解决方案是建立两个平行的表示空间，让所有输入信息分批汇入这两个空间，再通过若干轮迭代精化让它们相互融合。

---

## 2. 两个基本表示空间：单体表示与配对表示

整个模型的核心是两个贯穿始终的张量：

### 单体表示（Single Representation，记为 s）

- **形状**：`[N_token, 384]`
- **语义**：每个 token（残基或配体原子）一个 384 维向量，描述该 token 自身的化学属性、局部环境、进化特征
- **类比**：词嵌入——每个"词"（token）有一个密集向量表示其含义

### 配对表示（Pair Representation，记为 z）

- **形状**：`[N_token, N_token, 128]`
- **语义**：每对 token (i, j) 一个 128 维向量，描述这两个 token 之间的关系——距离、方向、相互作用可能性
- **类比**：关系矩阵——描述"词 i 和词 j 之间的关系"

这两个空间相互依赖、相互更新。单体表示提供"个体"信息，配对表示提供"关系"信息，最终模型从配对表示中读取出"哪些 token 应该在空间上接近"的预测。

**为什么需要两个空间？**

仅靠单体表示（类似于 BERT 中的词嵌入）不够，因为结构预测的核心问题是"哪些残基相互接触"——这是成对关系，必须用成对表示建模。仅有配对表示计算量太高（N² 的规模在大型复合物中非常巨大），且无法高效传播单个 token 的自身属性。两者并存，既高效又完备。

## 3. 输入的六条信息流

模型输入的特征字典包含六类信息，它们通过不同路径流入模型：

| 信息流 | 来源 | 进入模型的方式 | 最终影响 |
|--------|------|--------------|---------|
| **原子化学属性** | ref_element, ref_charge, ref_atom_name_chars | 原子注意力编码器 → 聚合到 token → 汇入 s_inputs | s 和 z 的初始化 |
| **序列与演化摘要** | restype, profile, deletion_mean | 直接拼接到 s_inputs | s 和 z 的初始化 |
| **空间位置关系** | residue_index, asym_id, entity_id, sym_id | 相对位置编码 → 加入 z_init | z 的初始化 |
| **键合拓扑** | token_bonds | 线性投影 → 加入 z_init | z 的初始化 |
| **MSA 进化信息** | msa, has_deletion, deletion_value | MSA 模块 → 更新 z | 每次循环中更新 z |
| **模板结构先验** | template_distogram, template_unit_vector, ... | 模板嵌入器 → 更新 z | 每次循环中更新 z |

可以看出：前四条信息流在**模型初始化阶段**一次性注入，后两条信息流在**每次循环迭代**中持续注入。这是有意为之的设计——序列和结构拓扑是稳定的先验知识，而 MSA 和模板提供的是迭代细化所需的外部约束信号。

## 4. 第一步：原子级嵌入——将化学属性变为向量

### 输入原子的特征是什么

每个原子携带四类化学信息：
- **元素类型**（ref_element）：128 维 one-hot，表明这个原子是碳、氮、氧、硫还是其他元素
- **形式电荷**（ref_charge）：整数，表明原子的静电状态
- **原子名称字符**（ref_atom_name_chars）：4 个字符的 ASCII 码，如 "CA" 或 "OG1"
- **原子间相对位置**（d_lm）：与附近原子的三维位移向量

最后一项（d_lm）是在进入模型的第一步就计算出来的预处理特征：对每个原子，找出其最近邻的 128 个原子，计算与它们的三维位移向量。这些位移向量捕捉了原子的**局部几何环境**——周围原子的分布形状隐含了该原子的化学状态（是否成键、在骨架还是侧链、局部构象）。

同时计算 v_lm：相邻原子是否与中心原子属于**同一残基**——这是一个布尔标记，让模型区分"残基内部"和"残基间"的原子对，因为两者的相互作用性质截然不同。

### 原子注意力编码器的逻辑

这一步的本质是**局部原子邻域的自注意力**。每个原子关注它周围 128 个最近邻原子，通过注意力权重聚合邻域信息，更新自身的向量表示。

注意力的偏置（attention bias）由两个来源决定：
- **原子对特征**（atompair features）：由 d_lm（相对位置）和 v_lm（是否同残基）线性变换得到，直接影响注意力权重，让模型知道"近的原子对"和"同残基的原子对"权重更高
- **原子自身特征**：查询和键值的初始化都来自原子本身的化学属性

经过若干层自注意力后，每个原子都有了一个 128 维的向量，编码了"它是什么元素、带多少电荷、叫什么名字、周围的局部构型是什么"的综合信息。

### 从原子聚合到 token

模型的主干（Pairformer 等）工作在 token 粒度，而不是原子粒度。因此原子级向量需要聚合到 token 级：对每个 token，将其包含的所有原子的向量**求和**（sum aggregation），得到一个 384 维的 token 级向量。

聚合后的向量代表"这个残基（或配体原子）的原子集合作为整体呈现出的化学特征"。蛋白质残基有多个原子，其聚合向量综合了骨架原子和侧链原子的信息；配体原子只有一个原子，聚合等同于直接提取。

## 5. 第二步：输入嵌入器——汇聚成 s_inputs

原子聚合向量（384 维）不是 token 特征的全部。输入嵌入器（InputFeatureEmbedder）将三类信息**拼接**在一起，形成完整的输入表示 `s_inputs`：

```
s_inputs = [原子聚合向量 (384) | restype one-hot (32) | MSA profile (32) | deletion_mean (1)]
           ──────────────────────────────────────────────────────────────────────────────────
                                     合计：449 维
```

这三段信息各有其不可替代的角色：

**原子聚合向量（384 维）**：来自原子级物理化学属性，编码"这个残基由什么原子组成、局部几何如何"。它是唯一知道原子三维相对位置的输入信息（通过 d_lm）。

**restype one-hot（32 维）**：直接的序列信息，告诉模型"这是哪种氨基酸/碱基"。这是最简洁、最明确的化学类型标签。你可能会问：原子向量不已经包含了化学类型信息吗？是的，但通过 one-hot 再次显式给出，减少模型从原子级特征"重新推断"残基类型的负担。

**MSA profile（32 维）**：每个位置上的氨基酸频率分布，是 MSA 信息的浓缩摘要。它不告诉模型"具体哪条同源序列在这里是什么氨基酸"，而是告诉模型"在进化历史上，这个位置倾向于出现哪些氨基酸"。这种统计摘要在 s_inputs 阶段就注入，让后续的所有模块都能感知到进化保守性。

**deletion_mean（1 维）**：这个位置在 MSA 中平均有多少插入/缺失，作为补充的进化信号。

**可选：ESM 嵌入**

若启用了 ESM（Evolutionary Scale Modeling，一种预训练蛋白质语言模型），ESM 预先对序列计算出 2560 维的上下文嵌入，通过一个线性层投影到 449 维后**直接加到 s_inputs** 上。这是一种残差注入方式：线性层的权重初始化为全零，意味着在训练开始时 ESM 的贡献为零，随着训练进行模型逐渐学习如何利用语言模型知识。

## 6. 第三步：初始化两个表示空间

有了 449 维的 `s_inputs` 后，模型开始构建两个工作表示空间：

### 初始化单体表示 s_init

`s_inputs` 经过一个线性层（无偏置），从 449 维压缩到 384 维，得到 `s_init`。这一步是维度对齐——后续 Pairformer 的所有模块都期待 384 维的单体向量。

### 初始化配对表示 z_init

配对表示的初始化是一个**外积加法**（outer sum）操作：

对 `s_init` 做两次不同的线性投影（都是 384→128 维），得到两组 token 向量。然后：
- 第一组向量中每个 token 的向量作为"行向量"广播到所有列
- 第二组向量中每个 token 的向量作为"列向量"广播到所有行
- 两者逐元素相加

结果是一个 `[N_token, N_token, 128]` 的矩阵，第 (i, j) 位置的向量 = 「token i 的行特征」+「token j 的列特征」。

这个初始化的含义：在任何训练信号介入之前，对 (i, j) 这对 token 的初始"关系感知"只是它们各自属性的简单叠加——我不知道你们的关系，就先用"你的特征加我的特征"作为起点。后续 MSA 和模板信息会逐步修正这个初始猜测。

## 7. 第四步：相对位置编码——让模型知道"谁和谁相邻"

注意力机制本身是**位置无关**的——它看一个序列时不知道第 5 个元素和第 6 个元素是相邻的。必须通过位置编码显式注入"相对距离"信息。

### Protenix 的位置编码携带什么信息

相对位置编码（`relp`）生成一个 `[N_token, N_token, D_relp]` 的张量，为每对 token (i, j) 编码：

**残基间距**：i 和 j 在序列上相差多少个位置。Protenix 使用 one-hot 编码的离散距离桶（bucket），而非连续的绝对差值。这样能区分"相邻（差1）"、"近邻（差2-4）"、"较近（差5-12）"、"远（差 > r_max）"等不同的序列距离档位。

**链身份**：i 和 j 是否属于同一条链（`asym_id` 是否相同）。跨链的 token 对没有序列上的相邻关系，需要特殊标记。

**实体身份**：i 和 j 是否来自同一种实体（`entity_id` 是否相同）。同一种蛋白质的不同拷贝（sym_id 不同）应该有独特的位置感知方式。

### 为什么需要相对而非绝对位置

绝对位置编码（第 1 个 token、第 2 个 token...）会让模型对裁剪边界敏感——同样的结合口袋，若位于序列第 50 位和第 500 位，绝对编码会给出完全不同的表示，但两者应该具有相同的结构特征。相对编码只关心"你们相差多少"，不关心"你们在第几位"，天然具有平移不变性。

相对位置编码线性投影到 128 维后，**直接加到 z_init 上**，成为配对表示的一部分。

## 8. 循环精化：四轮迭代的信息汇聚

到目前为止，z_init 包含了：初始的外积化学特征 + 相对位置编码 + 键合拓扑。这些都是**静态先验**——不依赖 MSA 和模板的固定信息。

接下来进入核心的**循环精化阶段**（N_cycle = 4 轮），每一轮都会依次通过三个模块更新 s 和 z：

```
每一轮循环的顺序：
  1. 模板嵌入器 → 更新 z（注入结构先验）
  2. MSA 模块   → 更新 z（注入进化约束）
  3. Pairformer  → 深度更新 s 和 z（推理综合）
```

四轮之后，s 和 z 承载了来自所有信息源的充分融合表示，被送往下游的三个输出模块。

## 9. 第一轮更新：模板嵌入器——注入结构先验

**输入**：z（当前配对表示）+ 所有模板的几何特征

**输出**：更新后的 z

### 模板信息的形态

每个模板提供的是关于 token 对 (i, j) 的几何关系：
- distogram（39 维）：i 和 j 在模板中的距离属于哪个距离桶
- unit_vector（3 维）：j 相对于 i 的方向向量
- 模板残基类型（各 32 维）：模板中位置 i 和位置 j 各是什么氨基酸

这些特征拼接成每对 token 的 108 维向量。

### 嵌入方式

对每个模板，108 维向量与当前 z 融合（线性变换后相加），再经过一个小型 Pairformer（只更新配对表示，不涉及单体表示），提炼出"这个模板对这对 token 的关系暗示了什么"。

多个模板的输出**取平均**（除以模板数量），得到综合模板贡献，加到 z 上。

### 零初始化的深层含义

模板嵌入器输出的最终线性层权重初始化为零。这意味着在训练最开始，模板完全不影响 z——模型先学会从序列和位置信息预测结构，再逐渐学习如何借助模板。这种渐进式学习防止了模型在训练初期对模板过度依赖（模板不总是可靠的）。

---

## 10. 第二轮更新：MSA 模块——注入进化信息

**输入**：z（当前配对表示）+ MSA 矩阵

**输出**：更新后的 z

### MSA 的嵌入过程

MSA 矩阵形状是 `[N_msa, N_token]`，每行是一条同源序列。处理时先将每行的每个位置编码：
- 氨基酸类型：32 维 one-hot
- 是否有 gap：1 维
- gap 长度：1 维

三者拼接成 34 维，线性投影到 MSA 嵌入维度（64 维），形成 MSA 嵌入矩阵 `m`，形状 `[N_msa, N_token, 64]`。

同时，将 token 级的单体表示 s 广播到每一行，加入 MSA 嵌入——告诉每条 MSA 序列"对应的 query 残基当前的特征是什么"。这个操作建立了 MSA 与当前模型状态的连接：MSA 处理不是静态的，而是感知 query 当前状态的。

### MSA 模块的核心机制：外积均值

MSA 模块中最关键的操作叫**外积均值（Outer Product Mean）**。

直觉：对每对 token (i, j)，计算 MSA 中所有序列在位置 i 的特征向量与位置 j 的特征向量的外积，再取均值。

这个操作的意义：如果在所有同源序列中，位置 i 的特征和位置 j 的特征**系统性地相关**（某类序列中 i 是极性氨基酸时 j 也是极性氨基酸），外积均值就会产生一个非零的相关信号，注入到配对表示 z 中，告诉模型"这两个位置在进化上协变，可能在空间上相互作用"。

这正是从 MSA 到 z 的信息传递路径：**共进化信号 → 外积均值 → 配对表示 z 的更新**。

### 行注意力与对称结构

MSA 矩阵是行（序列）× 列（token 位置）的二维结构。MSA 模块在行方向做注意力：每一行（一条同源序列）的每个位置关注同行其他位置，基于 z 中的配对信息作为偏置权重。这让 MSA 的处理感知到 query 结构的空间约束，避免了 MSA 处理与结构信息的割裂。

---

## 11. 第三轮更新：Pairformer——深度推理

**输入**：s（单体表示）+ z（配对表示）

**输出**：更新后的 s 和 z

Pairformer 是整个模型中参数量最大、计算量最重的部分，共 48 个块（block）串联。每个块做四件事：

### 三角注意力（Triangular Attention）

这是 Pairformer 的核心创新，专为**成对关系**的推理设计。

**直觉类比**：若已知 A-B 之间的距离和 B-C 之间的距离，可以推断 A-C 之间的距离范围（三角不等式）。模型在 z 矩阵上实现了这个推理：

- **行方向三角注意力**：对每对 (i, k)，收集所有中间节点 j 的贡献：z[i,k] 被 {z[i,j], z[j,k]} 更新。可以理解为：i 到 k 的关系，由"i 到所有 j 的关系"和"j 到 k 的关系"共同约束。

- **列方向三角注意力**：类似地，从另一个方向推理。

- **三角乘法（Triangle Multiplication）**：z[i,k] 由 z[i,j] ⊗ z[j,k] 求和更新，这是注意力的简化高效版本。

48 层的重复堆叠让模型能够进行复杂的多跳推理：从局部的化学相互作用，推理出全局的三维折叠拓扑。

### 配对偏置的单体注意力

单体表示 s 也需要更新，但不是独立更新——而是以 z 作为注意力偏置：token i 关注 token j 时，注意力权重由 z[i,j] 中编码的成对关系调控。

这创造了单体表示和配对表示之间的**双向耦合**：
- z 的更新通过三角注意力感知 s 的当前状态（经由外积等操作）
- s 的更新通过配对偏置注意力感知 z 的当前状态

两者在每个 Pairformer 块中交替相互驱动，逐层深化对结构的理解。

### 前馈变换（Transition）

每次注意力更新后，s 和 z 分别经过独立的前馈神经网络（两层 MLP + 非线性激活），增加表示的非线性表达能力。

---

## 12. 循环连接：上一轮如何影响下一轮

四轮循环不是简单地重复四次相同的计算——每一轮的输入都包含了上一轮的精化结果。

### 连接方式

上一轮 Pairformer 输出的 s 和 z 经过 LayerNorm 归一化后，通过线性投影，**加回到本轮的初始 z_init 和 s_init 上**，作为本轮的起点。

这是一个**残差连接跨轮次**的设计：
- `z_本轮初始 = z_init + proj(LayerNorm(z_上一轮))`
- `s_本轮初始 = s_init + proj(LayerNorm(s_上一轮))`

`z_init` 和 `s_init` 始终固定不变（来自最初的嵌入），循环连接的贡献叠加在上面。

### 零初始化的关键设计

这两个循环连接的线性层权重初始化为**全零**。这意味着：
- 第一轮循环从 z_init 和 s_init 出发，不受任何上一轮影响（因为线性层输出全零）
- 随着训练进行，循环连接的权重从零开始学习，逐步学会"如何利用上一轮的预测来改进当前轮次"
- 这保证了训练初期的稳定性——模型不会在还没学到任何东西时就产生混乱的循环反馈

### 循环的作用：迭代精化

每一轮循环都在上一轮的基础上对结构理解做进一步精化。第一轮 Pairformer 给出粗略的接触预测，第二轮在此基础上精化局部几何，第三轮调整侧链，第四轮微调精度。

这类似于绘画时"先勾勒轮廓，再逐步细化"的过程——全局折叠拓扑先确定，局部细节后填充。

---

## 13. 三路输出：三个下游模块的分工

四轮循环结束后，模型维持三个张量作为共享的"总结表示"：
- `s_inputs`（449 维，来自输入嵌入器，不参与循环）
- `s`（384 维，Pairformer 最终输出的单体表示）
- `z`（128 维，Pairformer 最终输出的配对表示）

这三个张量被**同时送往三个下游模块**：

```
         ┌─────────────────────────────────────────────────┐
         │   s_inputs (449)  +  s (384)  +  z (128)        │
         └──────────────────┬──────────────────────────────┘
                            │
             ┌──────────────┼──────────────┐
             ↓              ↓              ↓
      Distogram Head   Diffusion Module   Confidence Head
      (距离图预测)      (三维坐标生成)     (质量评估)
```

---

## 14. 扩散模块：从表示到三维坐标

扩散模块（Diffusion Module）是最终生成三维坐标的地方。它的工作原理来源于**扩散生成模型**（Diffusion Model）的思想：

### 扩散模型的基本逻辑

训练时：向真实原子坐标加入不同程度的高斯噪声，让网络学会"从带噪声的坐标中恢复出干净的坐标"。

推理时：从纯噪声出发（所有原子坐标都是随机高斯噪声，σ_max = 160 Å），通过反复去噪，逐步逼近真实结构（约 200 步迭代）。

### 表示如何条件化扩散过程

`s` 和 `z` 作为**条件信号（conditioning）**注入扩散过程：

**单体条件**：`s` 和 `s_inputs` 拼接后，加上**噪声水平的傅里叶编码**（告诉模型"当前的噪声有多大"），形成逐 token 的条件向量。不同噪声水平下，模型应有不同的去噪策略：噪声很大时做全局折叠，噪声很小时做局部精细调整。

**配对条件**：`z` 加上相对位置编码，形成 token 对之间的条件信号，直接作为去噪注意力的偏置权重。z 中编码的"这两个 token 应该相距约 5 Å"的信息，通过注意力偏置告诉扩散网络"关注这两个原子的位置约束"。

### 去噪网络：原子级 Transformer

扩散模块内部的去噪网络与外层 Pairformer 不同——它工作在**原子粒度**，而不是 token 粒度。每一步去噪：

1. 把当前带噪声的原子坐标，加上 `s` 中的 token 级特征（广播到原子级），加上 `z` 中的配对约束（作为注意力偏置）
2. 通过原子级自注意力，计算预测的去噪方向
3. 更新坐标，向干净坐标迈进一步

工作在原子粒度保证了输出是真正的全原子三维结构，而不是粗粒度的残基位置。`z` 从 token 空间桥接到原子空间时，通过 `atom_to_token_idx` 映射扩展。

### 多样性采样

推理时不只运行一次扩散过程，而是运行 5 次（N_sample = 5），每次从不同的随机噪声种子出发，得到 5 个候选结构。这反映了蛋白质结构的天然多样性——同一条序列可能有多种构象，模型通过多次采样给出不同的可能结构，再由置信度模型选出最优的。

---

## 15. 置信度头：自我评估预测质量

置信度头（Confidence Head）是 Protenix 的自评估模块，它接受 `s_inputs`、`s`、`z` 以及**扩散模块刚刚预测出的原子坐标**，输出多种质量指标：

### 四类置信度输出

**pLDDT（局部距离差测试分数）**：每个原子的预测质量分数（50 个等级桶，0 到 1）。反映该原子相对于周围原子的局部几何是否可信。高 pLDDT 的区域（通常 > 0.7）表示模型对该区域的结构很有把握，低 pLDDT 的区域（< 0.5）说明模型认为该区域有多种可能构象或预测不可靠。

**PAE（预测对准误差）**：每对 token (i, j) 的相对位置预测误差估计（64 个等级桶，单位埃）。低 PAE 表示模型认为 token i 和 j 的相对位置可靠，高 PAE 表示不确定。PAE 矩阵可以可视化为热图，帮助用户判断哪些结构域之间的相对位置是可信的。

**PDE（预测距离误差）**：每个 token 的平均距离预测误差。是对 PAE 的每 token 汇总。

**Resolved（可解析性）**：预测该原子是否在真实结构中"可被实验解析"（2 类：可解析 / 不可解析）。不可解析通常意味着该区域在生物学上是柔性的（如 loop 区域），或者序列在功能状态下是无序的。

### 置信度头的内部结构

置信度头内部有一个小型 Pairformer（4 个块），比主干的 48 个块轻得多。它的输入不只是 s 和 z，还包括**预测坐标之间的距离矩阵**——计算预测原子间的距离，离散化后编码，加入配对表示，让置信度预测感知到"当前预测的原子坐标实际暗示什么样的距离分布"。

这是一个自参照的设计：模型先生成坐标，再根据坐标来评估自己生成的坐标有多可信。

---

## 16. 可选输入的接入方式

### 约束特征（Constraint Features）

当用户提供额外的实验约束（如距离约束、接触约束、结合口袋信息）时，这些约束通过独立的约束嵌入器（ConstraintEmbedder）处理，输出同样是 128 维的配对特征，**直接加到 z_init 上**。

接入点在 z_init 阶段（最早期），保证约束信息从一开始就参与所有循环轮次的更新，具有最大的影响力。

### ESM 语言模型嵌入

ESM2 是在数亿条蛋白质序列上预训练的语言模型，能为每个残基输出 2560 维的上下文感知嵌入。这些嵌入通过线性投影（2560 → 449 维）后**加到 s_inputs 上**，在嵌入阶段最早期注入。

初始化为零的设计确保了向后兼容：没有预计算 ESM 嵌入时，整个 ESM 分支贡献为零，模型行为与不使用 ESM 时完全相同。
