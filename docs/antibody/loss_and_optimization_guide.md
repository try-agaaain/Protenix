## 1. 模型输出的整体结构

本文承接 [模型输入数据流完全指南](model_input_guide.md)，介绍模型的输出、损失计算与优化策略。Protenix 在每次前向传播中产生三类输出，它们从三个独立的模块并行输出：

```
Pairformer 最终表示（s, z）
          │
          ├─────────────────────────────────┐
          │                                 │
          ↓                                 ↓
   扩散模块（Diffusion）            距离图头（Distogram Head）
   → 全原子三维坐标                 → token 对距离分布
          │
          ↓
   置信度头（Confidence Head）
   → pLDDT / PAE / PDE / Resolved
```

三类输出各自针对不同的预测目标，对应不同的损失函数，共同驱动模型的学习。

**训练时与推理时的区别**：
- 训练时输出包含**多个扩散样本**（通常 1 个用于损失计算）+ **真值对比所需的所有中间量**
- 推理时输出 **5 个扩散样本**，通过置信度排名选出最优结构，同时输出置信度图用于结果可视化

## 2. 坐标输出：全原子三维坐标

扩散模块输出的是**全原子三维坐标**，形状为 `[样本数, 原子数, 3]`。

每个原子有三个浮点数 (x, y, z)，单位是埃（Å）。这是最直接的结构预测结果——可以直接用于可视化、对接、分子动力学模拟等下游应用。

训练时产生两种坐标：

**Mini-rollout 坐标（20 步快速去噪）**：在完整扩散（200 步）之前，先做一个 20 步的"快速预览"。这个粗糙的预测被用于：
- 对称置换判断（决定如何对齐预测与真值）
- 置信度损失的监督信号（PAE、PDE 等）

**Full-rollout 坐标（200 步完整去噪）**：最终的坐标预测，对应 MSE 损失、SmoothLDDT 损失、Bond 损失的监督目标。

**为什么用两种坐标？** Mini-rollout 在计算成本更低的情况下给出"足够好"的结构，足以让置信度头学习预测误差的分布；Full-rollout 才是结构预测的真正输出，享受完整的去噪步骤。

## 3. 置信度输出：四类自我评估指标

置信度头输出的不是最终分数，而是**概率分布的 logits**，每类指标对应若干离散"桶"（bin）：

### pLDDT（每原子局部距离差置信度）

- **形状**：`[样本数, 原子数, 50]`，50 个置信度桶
- **含义**：模型对该原子局部几何是否准确的信心，最终聚合为 0-100 的分数
- **高分（>70）**：该原子周围的局部结构预测可靠
- **低分（<50）**：该区域可能是柔性区域或预测不确定

### PAE（预测对准误差）

- **形状**：`[样本数, 帧数, token 数, 64]`，64 个误差桶（0-32 Å 范围）
- **含义**：在以 token i 的局部坐标系为参考、对预测结构做最优刚体对齐后，token j 的位置误差有多大
- **低 PAE（<5 Å）**：这两个 token 的相对位置预测可靠
- **高 PAE**：相对位置不确定（常见于多构象的 loop 区域，或两个结构域之间的柔性连接处）

### PDE（预测距离误差）

- **形状**：`[样本数, token 数, token 数, 64]`，64 个误差桶
- **含义**：每对 token 之间的代表原子距离的预测误差有多大
- **PAE 与 PDE 的区别**：PAE 在局部坐标系下计算，去除了全局对齐的影响，更适合多链复合物；PDE 直接评估距离预测的精度，更直观

### Resolved（是否可被实验解析）

- **形状**：`[样本数, 原子数, 2]`，二分类（不可解析 / 可解析）
- **含义**：模型预测该原子在实验中是否能被观测到
- **应用**：识别蛋白质中天然无序（intrinsically disordered）的区域

## 4. 距离图输出：粗粒度空间分布

距离图头（Distogram Head）直接从 Pairformer 的配对表示 z 生成，不经过扩散：

- **形状**：`[token 数, token 数, 64]`，64 个距离桶（约 2.3 Å 到 21.7 Å）
- **含义**：每对 token 的代表原子（蛋白质用 Cβ，RNA 用 C4'）之间的距离属于哪个区间的概率分布
- **不对称 → 对称化**：原始输出可能不对称（i 到 j 和 j 到 i 的预测可能不同），模型强制将矩阵与其转置相加后使用，保证距离预测的对称性

距离图的输出不直接用于最终结构，而是作为**辅助监督信号**：它比扩散模块更早产生，能在训练前期对 Pairformer 提供粗粒度的空间约束反馈。

## 5. 损失函数体系概览

Protenix 共有八个损失函数，按职责分为三组：

```
坐标精度组（主导训练）
  MSE 损失            ← 直接回归坐标误差
  SmoothLDDT 损失     ← 局部距离精度
  Bond 损失           ← 化学键长度约束

空间引导组（辅助训练）
  Distogram 损失      ← 粗粒度距离分布

自评估组（置信度训练）
  pLDDT 损失          ← 每原子局部质量
  PDE 损失            ← token 对距离误差
  PAE 损失            ← 帧对齐误差
  Resolved 损失       ← 实验可解析性
```

每个损失都回答一个具体的问题：**预测的某个属性与真值相差多少？**

---

## 6. MSE 损失：坐标回归的基础

**问题**：预测的原子坐标与真实原子坐标差了多少？

**直觉**：最直接的结构损失——对每个原子，计算预测坐标与真值坐标之间的平方差，取均值。

### 刚体对齐为什么不可省略

若直接逐原子计算坐标差，蛋白质在空间中的绝对位置和朝向是任意的——同一个预测结构旋转 90° 后与真值相比，均方误差会大幅增大，但结构本身完全正确。因此，必须在计算损失之前对真值坐标进行**刚体对齐**（只做旋转和平移，不改变结构形状），找到让真值最接近预测的那种朝向，再计算差异。

这里有一个细节：对齐是在**无梯度**的情况下计算的（对齐参数不反向传播）。原因是：如果对齐操作本身也有梯度，模型可能学到"通过改变预测坐标来影响对齐结果，从而减小对齐后的误差"，这是一种作弊——模型应该学会预测正确结构，而不是学会操纵对齐。

### 差异化权重的逻辑

对齐使用加权刚体对齐，不同类型原子的权重不同：

| 分子类型 | 对齐权重 |
|---------|---------|
| 蛋白质 | 1.0（基准） |
| DNA | 6.0（基准 + 5） |
| RNA | 6.0（基准 + 5） |
| 配体 | 11.0（基准 + 10） |

**为什么配体权重最高？** 配体（小分子药物、辅因子等）通常结合在蛋白质的特定口袋中，其位置预测是药物设计的核心关注点。更高权重意味着对齐时优先让配体位置匹配，而不是让整个蛋白质主链对齐。DNA 和 RNA 同样因为功能关键性而获得较高权重。

### 噪声水平加权

MSE 损失还受到扩散噪声水平的调制。当噪声水平 σ 很高时（早期去噪步骤，结构很模糊），损失系数会相应放大；噪声水平低时（后期精细去噪），损失系数保持较小。这确保了模型在每个噪声级别上都受到均等的训练压力，防止只在低噪声阶段收敛良好而忽视高噪声阶段的全局折叠能力。

## 7. SmoothLDDT 损失：局部几何的精细约束

**问题**：预测结构的局部几何是否准确？

**背景**：MSE 损失关注绝对坐标误差，但有一种失败模式是"整体折叠大致正确，但局部骨架扭曲"。SmoothLDDT（平滑局部距离差测试）专门针对这类局部误差。

### 核心逻辑：软化的距离准确率

对每个原子 i，找出它在真实结构中一定范围内（蛋白质/配体用 15 Å，核酸用 30 Å）的所有原子 j，计算每对 (i, j) 的预测距离与真实距离的差值，再用四个阈值（0.5 Å、1.0 Å、2.0 Å、4.0 Å）衡量距离有多准确——每个阈值下的"符合率"越高说明越准确。

四个阈值的平均即为该原子的局部距离差得分，将所有原子和所有有效对的得分取均值，最终损失 = 1 - 平均得分。

**为什么是"Smooth"（平滑）版本？** 标准 LDDT 使用硬性阈值（达到就是 1，没达到就是 0），梯度在阈值处不连续。Smooth 版本用 sigmoid 函数平滑阈值判断，使损失对坐标变化有连续梯度，利于反向传播优化。

**与 MSE 损失的互补关系**：MSE 在全局刚体对齐后计算，对全局平移不敏感，但对局部扭曲不够敏感。SmoothLDDT 基于局部距离，不需要全局对齐，对局部几何变化极为敏感。两者结合，全局和局部精度都有约束。

## 8. Bond 损失：化学键的硬约束

**问题**：预测结构中的共价键键长是否合理？

**背景**：MSE 和 SmoothLDDT 都着眼于整体结构质量，但对单个键长的约束不够精确。共价键有严格的物理键长范围（C-N 肽键约 1.33 Å，C-C 键约 1.52 Å），违反这些约束的结构在化学上不可行。

Bond 损失对每对成键原子计算预测键长与真实键长的**平方差**，只统计实际有共价键的原子对（通过键合掩码 bond_mask 过滤），忽略无键原子对。

**为什么训练初期关闭（alpha_bond = 0）？** Bond 损失要求模型已经大致预测出正确的骨架几何才有意义。训练初期，模型对全局折叠的理解还很粗糙，过早约束键长反而会干扰全局折叠的学习。因此 Bond 损失只在**后期微调阶段**激活（详见[第 15 节](#15-三阶段训练策略)），在全局结构已经大致准确的基础上再精化化学细节。

## 9. Distogram 损失：序列引导的空间监督

**问题**：模型从纯序列信息预测出的 token 对距离分布是否正确？

Distogram 损失是唯一**不依赖扩散模块输出**的结构损失，直接监督 Pairformer 配对表示 z 的质量。

**地面真值的生成**：提取每个 token 的代表原子（蛋白质取 Cβ 碳，GLY 取 Cα，RNA/DNA 取特定核糖碳）在真实结构中的坐标，计算所有代表原子对之间的真实距离，将距离离散化到 64 个桶中，得到 one-hot 标签。

**损失形式**：对每对 token，计算 64 维预测分布与 one-hot 真值之间的交叉熵，只统计两个代表原子都有坐标的有效对。

**为什么权重很小（0.03 vs 扩散的 4.0）？** Distogram 损失提供的是**粗粒度**的空间约束，精度有限（64 桶量化了距离信息），且监督的是 token 级代表原子而非全原子。扩散损失监督的是完整的全原子坐标，信息量更丰富，因此主导训练；Distogram 损失作为辅助信号，帮助 Pairformer 在扩散之前就建立合理的空间关系预测。

## 10. 置信度相关损失：四个自评估目标

置信度损失的逻辑是：让模型**诚实地预测自己的错误**。

这四个损失都基于同一个模式：
1. 用 mini-rollout（20 步快速去噪）得到一个中等质量的坐标预测
2. 把预测坐标与真值坐标进行比较，计算实际误差
3. 用这个实际误差作为标签，监督置信度头输出对应的置信度预测

### pLDDT 损失

实际误差：对 mini-rollout 坐标计算每原子的 LDDT 得分（参考 SmoothLDDT 的多阈值评分逻辑），得到每原子的实际局部准确度（0-1 之间），离散化到 50 个桶，作为 one-hot 标签。置信度头需要准确预测每原子落在哪个桶。

### PDE 损失

实际误差：计算 mini-rollout 预测的 token 对代表原子距离与真实距离之差的绝对值，离散化到 64 桶（0-32 Å）。置信度头需要准确预测每对 token 的距离误差大小。

### PAE 损失

实际误差：以每个 token 的局部坐标系（由主链三原子定义的坐标系）为参考，计算 mini-rollout 预测在此坐标系下的对准误差（相当于：如果用这个 token 的骨架对齐结构，其他 token 的位置会差多少）。离散化到 64 桶。

**PAE 的特殊价值**：在多链复合物中，两条链之间的相对位置预测质量比单链内部更重要，也更难。PAE 通过帧对齐的方式，恰好捕捉了这种跨链相对位置的不确定性。

### Resolved 损失

真值直接来自：该原子在原始 mmCIF 文件中是否有实验坐标（`ref_mask`）。有坐标为类别 1，无坐标（缺失/柔性区域）为类别 0。这是纯分类任务，用交叉熵损失。

### 分辨率条件滤波

四个置信度损失有一个共同的约束：**只对分辨率在 0.1 到 4.0 Å 之间的结构计算**。

原因：
- 低于 0.1 Å：几乎不存在，理论下界
- 高于 4.0 Å：结构质量太差（原子坐标的不确定性远超预测误差），用这类数据训练置信度头会引入大量噪声标签，反而损害置信度预测的准确性

NMR 结构（分辨率 = -1.0）直接被排除在置信度损失之外。

## 11. 损失的加权聚合逻辑

八个损失函数通过权重系数合并为一个总损失，权重设计体现了明确的优先级：

| 损失 | 权重系数 | 设计意图 |
|------|---------|---------|
| MSE 损失 | 4.0 | 最高权重，主导坐标回归 |
| SmoothLDDT 损失 | 4.0 × 1.0 = 4.0 | 与 MSE 平等，共同约束局部几何 |
| Bond 损失 | 4.0 × 0.0（初期）| 后期微调才激活 |
| Distogram 损失 | 0.03 | 辅助信号，重量极轻 |
| pLDDT 损失 | 0.0001 | 置信度为次要任务 |
| PDE 损失 | 0.0001 | 同上 |
| PAE 损失 | 0.0001 × 0.0（初期）| 仅在最终阶段激活 |
| Resolved 损失 | 0.0001 | 同上 |

### 权重差异的内在逻辑

**扩散损失（MSE + SmoothLDDT）权重 = 4.0**，比 Distogram（0.03）高 130 倍，是置信度损失的 40000 倍。这明确表达了任务优先级：生成准确结构是第一目标，预测自信度有多准是次要目标。

**置信度损失权重极低（1e-4）的原因**：置信度头的训练依赖扩散模块已经能产生有意义预测，在训练初期扩散输出还很差时，置信度的真值标签也不可靠，过大权重只会引入噪声。

### NaN 保护机制

在少数极端情况下（如全为缺失原子的样本），某个损失会产生 NaN。Protenix 对每个损失独立检查，若为 NaN 则记录警告并**跳过该损失**（不参与当前步骤的总损失计算），其余损失照常更新。这防止了单个异常样本导致整次训练崩溃。

## 12. 扩散噪声与损失的耦合

扩散模型训练的核心原则是**各噪声水平对模型的贡献应该均等**。

### 噪声水平的采样

训练时，每个扩散样本的噪声水平 σ 从对数正态分布采样，而非均匀分布。对数正态分布使低噪声和高噪声水平都有合理的采样概率，而不是大多数样本集中在中等噪声。

默认参数（均值 = -1.2，标准差 = 1.5，数据噪声尺度 = 16 Å）使采样的 σ 覆盖从几 Å（精细结构）到 160 Å（完全随机噪声）的宽广范围。

### 损失的噪声水平归一化

理论上，高噪声时预测误差天然更大，直接用 MSE 计算会导致高噪声样本的损失远大于低噪声样本，模型会更多地优化高噪声阶段，忽视低噪声阶段的精细化。

解决方案：将 MSE 损失乘以一个噪声归一化系数（与 σ² 相关的分式），使**不同噪声水平下的归一化损失具有相同量级**。这样，高噪声阶段（负责学全局折叠）和低噪声阶段（负责精细化）对模型参数的更新贡献是均衡的。

## 13. 对称置换：正确比较等价结构

### 问题的来源

许多蛋白质复合物具有对称性。例如同二聚体（homodimer）：两条完全相同的蛋白质链结合在一起。这样的结构中，链 A 和链 B 在物理上是等价的——调换两条链，得到的是同一个结构。

如果 Protenix 预测了一个同二聚体，预测结果可能是"链 A 在左、链 B 在右"，而真值标注的是"链 A 在右、链 B 在左"——两者描述的是**完全相同的结构**，但逐原子比较会显示出巨大差异。直接计算损失会产生虚假的高误差。

### 两级置换

Protenix 通过两级置换解决这个问题：

**链级置换**：对整条链进行重排，找到让预测与真值最对齐的链对应关系。例如：预测的第 1 条链对应真值的第 2 条链，预测的第 2 条链对应真值的第 1 条链。

**原子级置换**：在链内部，某些化学基团具有内部对称性（如谷氨酰胺侧链上的 OE1 和 OE2 是等价的，赖氨酸侧链末端的 NH1 和 NH2 是等价的）。原子级置换在链内部找到原子的最优对齐。

### 置换在训练流程中的位置

置换发生在 mini-rollout 之后、full-rollout 之前：

1. Mini-rollout 得到粗糙坐标预测
2. 对比预测与所有等价真值排列，找出最优对应关系
3. **更新真值标签**为选定的最优排列
4. Full-rollout 损失使用更新后的真值标签计算

这个时序设计很巧妙：mini-rollout 的粗糙预测已经足以判断哪种链对应关系更合理（两条链大致在左边还是右边），在此基础上确定的对应关系供 full-rollout 的精确损失使用。

## 14. 样本排名：如何从多个预测中选最优

推理时扩散模块生成 5 个独立候选结构（N_sample = 5），每个来自不同随机噪声初始化。置信度头对每个样本输出独立的置信度评分，最终通过排名公式选出最优：

### 三个中间置信度指标

**pTM（预测 TM 分数）**：衡量整体结构的全局质量。基于 PAE 矩阵，利用 TM-score 的数学形式（对距离依赖权重加权的期望值），估计预测结构与真实结构的整体相似度。值域 0-1，越高越好。

TM-score 权重的归一化因子依赖结构的 token 总数，使得不同大小的蛋白质的 pTM 具有可比性——大蛋白质和小蛋白质的 pTM 用同一把标尺衡量。

**ipTM（接口预测 TM 分数）**：与 pTM 计算方法相同，但**只统计不同链之间的 token 对**。对于多链复合物，链间接口的预测质量比单链内部更能反映预测的真实价值（任何合理的折叠预测都能给出较好的单链内部结构，而接口才是困难所在）。

**gPDE（全局预测距离误差）**：PAE 的另一种聚合方式，对 token 对按接触概率加权。高接触概率的 token 对（距离较近）贡献更大，使 gPDE 反映的是"接触残基之间的距离预测质量"，对配体结合口袋等关键区域尤为敏感。

### 排名公式

```
排名分数 = 0.8 × ipTM + 0.2 × pTM - 100 × has_clash
```

**权重 0.8 给 ipTM 的理由**：多链复合物（蛋白质-配体、蛋白质-蛋白质）的预测价值主要在接口；单体蛋白质的 ipTM 等于 pTM（只有一条链，所有对都是"链内"对），此时公式等效于 pTM。

**碰撞惩罚 -100**：如果预测结构中原子之间存在物理上不合理的碰撞（非键合原子距离过近，违反范德华半径），直接给排名分数减去 100，确保有碰撞的结构排在最后，无论其置信度分数多高。

### 链级和对级细粒度指标

除了每个样本的全局排名分数，系统还输出更细粒度的置信度：
- 每条链的平均 pLDDT
- 每条链的链内 pTM
- 每对链之间的 ipTM

这些细粒度信息帮助用户判断哪条链或哪个接口的预测更可信，对于分析复合物中的弱结合界面或柔性结构域特别有价值。

## 15. 三阶段训练策略

Protenix 的训练分为三个阶段，每个阶段的损失权重配置不同：

### 第一阶段：从头训练

**激活的损失**：MSE + SmoothLDDT + Distogram + 低权重置信度（pLDDT, PDE, Resolved）
**关闭的损失**：Bond（alpha_bond = 0），PAE（alpha_pae = 0）

**目标**：让模型先学会预测正确的全局折叠拓扑和局部几何。Bond 约束需要模型已有一定精度才有意义，过早引入反而干扰全局学习。PAE 需要配对框架（frame）坐标都准确才能产生有意义的监督信号。

### 第二阶段：置信度微调

**方式**：冻结扩散模块和 Pairformer，只训练置信度头

**激活的损失**：pLDDT + PDE + Resolved（均以 1e-4 权重），可选激活 PAE

**目标**：在已经能产生较好结构的模型基础上，专门优化置信度预测的准确性。若在第一阶段同时优化结构和置信度，两个目标之间的梯度干扰会使置信度学习不充分。解耦训练让置信度头专注于学习"如何诚实评估自己的预测质量"。

### 第三阶段：最终微调

**激活**：Bond（alpha_bond = 1），PAE（alpha_pae = 1）
**关闭**：SmoothLDDT（smooth_lddt = 0）

**目标**：在全局结构已经准确的基础上，精化化学键长（Bond 损失）和复合物界面的相对位置置信度（PAE 损失）。关闭 SmoothLDDT 的原因是此阶段局部几何已经足够好，不需要再施加强约束，反而为 Bond 和 PAE 的精化腾出"优化空间"。

## 16. 优化器与学习率调度

### 优化器选择：Adam

Protenix 使用标准 Adam 优化器，参数设置为：

| 参数 | 值 | 含义 |
|------|-----|------|
| β₁ | 0.9 | 一阶矩（梯度均值）的衰减系数 |
| β₂ | **0.95** | 二阶矩（梯度方差）的衰减系数 |
| weight_decay | 1e-8 | 极弱的 L2 正则 |
| 初始学习率 | 0.0018 | 相对较大的初始学习率 |

β₂ = 0.95（而非常见的 0.999）是关键选择：更小的 β₂ 意味着历史梯度方差的"记忆"更短，模型能更快响应近期梯度的变化。在扩散模型训练中，不同噪声水平的梯度方差差异很大，短记忆让优化器更灵活地适应这种差异。

### 学习率调度

分为两个阶段：

**预热阶段（10 步）**：学习率从 0 线性增长到初始学习率（0.0018）。直接用高学习率从随机初始化开始训练，早期梯度不稳定可能导致训练崩溃。预热让模型先进入稳定区域。

**指数衰减阶段**：每 50000 步，学习率乘以 0.95，但设有下限：不低于初始学习率的 10%（即 0.00018）。

衰减因子 0.95（而非激进的 0.5）意味着非常缓慢的衰减——每 50000 步只降 5%。这适合扩散模型的长程训练：过快衰减会导致后期学习率过低，无法进行必要的参数调整。

### 梯度裁剪

每步更新前，将梯度的 L2 范数裁剪到最大值 10.0。

梯度裁剪的必要性：扩散模型在训练初期和特定噪声水平下可能产生极大梯度，若不裁剪，一步更新就可能大幅破坏已学到的参数。裁剪保证了每步更新的"步长"有上界，即使偶发的极大梯度也不会造成灾难性的参数破坏。

## 17. 训练一步的完整流程

以下是一次完整训练步骤的操作顺序，每一步都有其逻辑依据：

```
Step 1：加载一批训练样本
  ← 已经过预处理的特征字典，包含真值坐标（coordinate）

Step 2：前向传播 —— Pairformer 部分
  输入特征 → InputEmbedder → s_inputs
  循环 4 次 → TemplateEmbedder + MSAModule + PairformerStack
  输出：s_inputs, s, z

Step 3：计算 Distogram 损失（可在扩散前完成）
  z → DistogramHead → 64 桶 logits
  与真值距离分布比较 → distogram_loss
  ← 早于扩散，为后续损失提供梯度基础

Step 4：Mini-rollout（20 步快速扩散）
  从噪声坐标出发，20 步去噪
  得到粗糙坐标预测 coordinate_mini

Step 5：对称置换（仅对称结构）
  比较 coordinate_mini 与所有等价真值排列
  选出最优对齐 → 更新 label_dict

Step 6：Full-rollout（200 步完整扩散，训练时通常只做 1 个样本）
  从噪声坐标出发，200 步去噪
  输出：coordinate [batch, 1, N_atom, 3]

Step 7：置信度头（基于 coordinate_mini）
  输入：s_inputs, s, z, coordinate_mini（detach，不传梯度）
  输出：plddt, pde, pae, resolved logits

Step 8：计算所有损失
  mse_loss        ← coordinate vs 真值（刚体对齐后）
  smooth_lddt     ← coordinate 局部距离 vs 真值
  bond_loss       ← 键合原子对距离 vs 真值（若 alpha_bond > 0）
  plddt_loss      ← plddt logits vs 真实 LDDT
  pde_loss        ← pde logits vs coordinate_mini 与真值的距离差
  pae_loss        ← pae logits vs coordinate_mini 的帧对齐误差（若激活）
  resolved_loss   ← resolved logits vs 原子坐标存在性

Step 9：加权求和
  total_loss = Σ(α_i × loss_i)
  NaN 检查：跳过异常损失
  分辨率过滤：置信度损失仅在 0.1-4.0 Å 范围内计算

Step 10：反向传播
  total_loss.backward()
  梯度裁剪（max norm = 10.0）

Step 11：参数更新
  optimizer.step()（Adam，β₁=0.9，β₂=0.95）

Step 12：学习率调度
  scheduler.step()
  当前 lr = max(lr_init × 0.95^(step/50000), lr_init × 0.1)

Step 13：记录指标
  所有分项损失、加权损失、总损失
  记录到日志/TensorBoard 供监控
```

以上 13 步在每次训练迭代中重复执行，经过数十万步后，模型从随机初始化逐步收敛到能准确预测生物大分子三维结构的状态。

## 附录：关键概念速查

| 概念 | 含义 |
|------|------|
| **pLDDT** | 每原子局部距离差测试分数，0-100，衡量局部几何可靠性 |
| **PAE** | 预测对准误差，在以某 token 为参考的坐标系中，其他 token 的位置误差（Å） |
| **PDE** | 预测距离误差，token 对之间距离的预测误差（Å） |
| **Resolved** | 预测该原子是否在实验中可被观测到 |
| **pTM** | 基于 PAE 估算的整体结构 TM-score，0-1 |
| **ipTM** | 仅基于跨链 token 对的 TM-score，衡量接口质量 |
| **gPDE** | 接触概率加权的全局 PDE，强调近距离 token 对 |
| **刚体对齐** | 只旋转平移真值坐标，不改变结构形状，消除全局位置的影响 |
| **对称置换** | 在链级和原子级找到等价排列中与预测最接近的那个 |
| **Mini-rollout** | 20 步快速扩散，生成中等质量坐标用于置信度训练 |
| **Full-rollout** | 200 步完整扩散，生成最终高质量坐标 |
| **噪声归一化** | 对不同噪声水平的损失做等权重归一化，防止高噪声阶段支配梯度 |
| **alpha 权重** | 各损失的系数，`total_loss = Σ(α_i × loss_i)` |
| **碰撞惩罚** | 排名分数 -100，确保有物理碰撞的结构排在最后 |
